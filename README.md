# Видеоплеер ГОСТФильм

Видеоплеер для уроков Devman «Верстаем видеоплеер» и «Добавляем плееру анимации».

[Открыть плеер](https://Arrrtemka246.github.io/devman-video-player/).

Работают запуск и пауза, выключение и включение звука, полноэкранный просмотр.
Плеер растягивает видео через Flexbox, оставляя место панели управления;
размеры внешнего контейнера задаются в классе `video-player`. JS-классы служат
подключению библиотеки, отдельные CSS-классы — оформлению.

## Локальный запуск

Нужен Python 3.10 или новее.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
livereload --host 127.0.0.1 -p 8012 .
```

Откройте http://127.0.0.1:8012/. Livereload сам обновляет страницу после
изменения HTML и CSS. Для остановки нажмите Ctrl+C.

Дополнительные упражнения урока: [HTML](examples/search.html) и
[Flexbox](examples/flex.html).

## Публикация

В настройках репозитория GitHub откройте **Pages**, выберите раздачу из ветки
`main`, папка `/ (root)`, и сохраните. После сборки сайт доступен по ссылке выше.
Ссылки на локальные ресурсы относительные, поэтому проект работает в подкаталоге
GitHub Pages. Тестовое видео загружается с учебного сайта Devman.

## Проверки

В Safari проверены запуск, пауза, смена кнопок звука, полноэкранный режим
и автоматическое обновление livereload. HTML проверяется W3C Nu Validator.

## Источники

- [Учебная библиотека Devman](https://github.com/devmanorg/video-player-jslib) — `player.js`.
- [jQuery 3.4.1](https://jquery.com/) и [Playable 2.10.3](https://github.com/wix/playable).
- [Font Awesome 4.7](https://fontawesome.com/v4/) — иконки.

Зависимости для браузера лежат в `vendor/`. Учебный проект [Devman](https://dvmn.org/).

## Таймер, перемотка и анимация

Урок «Добавляем плееру анимации» продолжает принятый прототип. Панель показывает
текущее время слева и длительность справа, между ними находится полоса перемотки.
Красная полоса и круглый ползунок с белой окантовкой используют цвет `#f8104d`.
Круг появляется при наведении на панель и исчезает при уходе курсора: 300 мс,
`ease-out` для появления и `ease-in` для исчезновения.

Шрифт Roboto 400, иконки и normalize.css загружаются локально. Стили вынесены
в `style.css`; JS-классы по-прежнему используются только для подключения
исходной библиотеки. Рамка после клика мышью убрана, клавиатурный фокус сохранён.

### Сравнение с макетом

Откройте [страницу наложения](https://arrrtemka246.github.io/devman-video-player/compare.html)
или локальный `/compare.html`. Ползунок регулирует прозрачность изображения.
При 50% можно сравнить кнопки, цифры и полоску с макетом; для сравнения кадра
остановите видео примерно на 6-й секунде. Рабочий плеер внутри рамки имеет
размер 800 × 600. Сама картинка включает внешние поля и тень.

Это способ сверки в Safari: [PerfectPixel](https://welldonecode.com/perfectpixel/)
предлагает расширения для Chrome, Edge и Firefox. Расширение в Safari не
устанавливалось. [Макет и записка дизайнера](https://gist.github.com/dvmn-tasks/c86e26be451abcf94f15b80189eb0390)
сохранены в `design/player.png` для воспроизводимого сравнения.

Упражнение по CSS hover: [examples/animation.html](examples/animation.html).
Источники: [Roboto](https://fonts.google.com/specimen/Roboto),
[normalize.css](https://necolas.github.io/normalize.css/). Их лицензии лежат рядом
с файлами в `vendor/`.

Для урока с анимациями в Safari дополнительно проверены таймер, перемотка,
появление и исчезновение ползунка, переключение звука и полный экран.
Веб-инспектор подтвердил загрузку Roboto и длительность перехода 0,3 с;
после перезагрузки без кеша консоль чистая. Карта исходников Playable тоже
сохранена локально. `index.html`, `compare.html` и `examples/animation.html`
прошли W3C Nu Validator без ошибок и предупреждений. Другие ОС и браузеры
этой проверкой не охвачены.
